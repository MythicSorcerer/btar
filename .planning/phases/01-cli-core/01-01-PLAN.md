<task type="auto">
  <name>Task 2: Implement core archive operations</name>
  <files>lib/archive.js</files>
  <action>
Create lib/archive.js with:

1. createArchive(files, outputPath):
   - Accept array of file paths
   - Create tar-format archive using Node.js built-in zlib and fs
   - Write to outputPath
   - Return success message

2. extractArchive(archivePath, outputDir):
   - Accept archive path and optional output directory
   - Extract using Node.js built-in modules
   - Handle common top-level prefix detection
   - Create subfolder if no common prefix
   - Return extraction summary

3. listArchive(archivePath):
   - Accept archive path
   - List contents with sizes and dates
   - Return formatted list

Use Node.js built-in tar-compatible streams (no external dependencies for v1).
  </action>
  <verify>
    <automated>node -e "import('./lib/archive.js').then(m => { console.log('createArchive:', typeof m.createArchive); console.log('extractArchive:', typeof m.extractArchive); console.log('listArchive:', typeof m.listArchive); })"
  </verify>
  <done>
    - createArchive(files, outputPath) creates valid archive file
    - extractArchive(archivePath) extracts to correct location
    - listArchive(archivePath) returns formatted file list
    - Archive operations work with .tar, .tar.gz, .tar.xz formats
  </done>
</task>

<task type="auto">
  <name>Task 3: Add error handling</name>
  <files>lib/errors.js</files>
  <action>
Create lib/errors.js with:

1. FileNotFoundError class:
   - Used when input file doesn't exist (ERR-01)
   - Message: "File not found: {filename}"

2. ArchiveError class:
   - Used for corrupted archives (ERR-02)
   - Message: "Invalid or corrupted archive: {filename}"

3. PermissionError class:
   - Used when can't read/write due to permissions (ERR-03)
   - Message: "Permission denied: {filename}"

4. Error handler functions:
   - handleError(error) - catch and format errors
   - validateFileExists(path) - check file exists before processing
   - validateArchive(archivePath) - check archive is valid

Update btar.js to catch errors and display user-friendly messages.
  </action>

  </verify>
  <done>
