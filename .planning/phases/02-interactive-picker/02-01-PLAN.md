<task type="auto">
  <name>Task 1: Implement interactive file picker</name>
  <files>lib/picker.js</files>
  <action>
Create lib/picker.js with:

1. runPicker() - main entry point:
   - Read current directory contents (fs.readdir)
   - Filter out hidden files, node_modules, etc.
   - Launch interactive UI if TTY, else show help
   - Return selected files array or null (cancelled)

2. displayGrid(files, selected, cursor, filter):
   - Display files in 2-column layout
   - Show search filter input value at top
   - Highlight selected files with [*]
   - Show cursor position with >
   - Max 10 files visible (5 lines, 2 columns)

3. handleKeyInput(key, state):
   - Arrow Up/Down: move cursor
   - Arrow Left/Right: move between columns
   - Space: toggle selection at cursor
   - Enter: confirm selection
   - Escape: cancel (return null)
   - Backspace/Delete: modify filter
   - Regular keys: add to filter

4. filterFiles(files, filter):
   - Case-insensitive filter matching
   - Filter applies to filename only
</action>
  <verify>
    <automated>node -e "import('./lib/picker.js').then(m => { console.log('runPicker:', typeof m.runPicker); console.log('displayGrid:', typeof m.displayGrid); console.log('handleKeyInput:', typeof m.handleKeyInput); })"
  </verify>
  <done>
    - runPicker() returns array of selected files or null
    - displayGrid() renders 2-column layout (PICK-01)
    - Search filter works (PICK-02)
    - Arrow keys + space for multiselect (PICK-03, PICK-04)
    - Enter confirms, Escape cancels (PICK-05)
  </done>
</task>

<task type="auto">
  <name>Task 2: Implement compression prompts</name>
  <files>lib/compression.js</files>
  <action>
Create lib/compression.js with:

1. promptCompression() - "Compress? (y/n)":
   - Accept user input via readline
   - Return true for 'y'/'Y', false for 'n'/'N'
   - Loop until valid input

2. promptFormat() - "Format: (g)z or (x)z?":
   - Accept 'g' or 'x' input
   - Return 'gz' or 'xz'
   - Loop until valid input

3. determineExtension(compressed, format):
   - If not compressed: return '.tar'
   - If compressed && format === 'gz': return '.tar.gz'
   - If compressed && format === 'xz': return '.tar.xz'

4. getOutputPath(selectedFiles, extension):
   - Generate output filename from first selected file
   - Format: {filename}.{extension}
   - Handle case: if no extension provided, use .tar
</action>
  <verify>
    <automated>node -e "import('./lib/compression.js').then(m => { console.log('promptCompression:', typeof m.promptCompression); console.log('promptFormat:', typeof m.promptFormat); console.log('determineExtension:', typeof m.determineExtension); })"
  </verify>
  <done>
    - "Compress?" prompt shown after selection (COMP-01)
    - "gz or xz?" prompt shown if compress=yes (COMP-02)
    - Plain .tar if compress=no (COMP-03)
    - Correct extension: .tar, .tar.gz, or .tar.xz (COMP-04)
  </done>
</task>

<task type="auto">
  <name>Task 3: Integrate picker into btar CLI</name>
  <files>btar.js</files>
  <action>
Update btar.js:

1. Import picker and compression modules:
   ```javascript
   import { runPicker } from './lib/picker.js';
   import { promptCompression, promptFormat, determineExtension, getOutputPath } from './lib/compression.js';
   ```

2. Modify main() to detect TTY vs args:
   - If process.stdin.isTTY && no process.argv[2]:
     → Call runPicker() to get file selection
     → If selection null (cancelled), exit gracefully
     → Call promptCompression()
     → If yes, call promptFormat()
     → Get output path with getOutputPath()
     → Call createArchive(selectedFiles, outputPath)
   - Else: existing behavior (Phase 1)

3. Ensure graceful handling when TTY unavailable:
   - If no TTY and no args: show help message
   - Don't attempt interactive mode in non-interactive context
</action>
  <verify>
    <automated>node -e "import('./btar.js').then(m => { console.log('main:', typeof m.main); })"
  </verify>
  <done>
    - Running btar with no args shows picker (TTY only)
    - Selection flow: picker → compress prompt → format prompt → archive
    - Creates correct extension based on compression choice
    - Non-TTY with no args shows help (not crash)
  </done>
</task>
