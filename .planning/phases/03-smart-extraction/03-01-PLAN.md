  <action>
Add a new function `detectCommonPrefix(files)` to lib/archive.js that:
1. Takes an array of file paths (e.g., ["dir/file1.txt", "dir/file2.txt", "dir/sub/file3.txt"])
2. Extracts the top-level component from each path (the first path segment)
3. Returns the common prefix if all files share the same top-level folder, or null if no common prefix

Implementation:
- Split each file path by '/' and take the first segment
- If all first segments are identical, return that segment as prefix
- If any differ, return null

Example:
- ["myproject/file1.txt", "myproject/file2.txt"] → returns "myproject"
- ["file1.txt", "file2.txt"] → returns null
- ["dir/a.txt", "other/b.txt"] → returns null
</action>
  <acceptance_criteria>
- detectCommonPrefix(["proj/a.txt", "proj/b.txt"]) returns "proj"
- detectCommonPrefix(["a.txt", "b.txt"]) returns null
- detectCommonPrefix(["dir/a.txt", "other/b.txt"]) returns null
- Function is exported for testing
</acceptance_criteria>
  <verify>
<automated>node -e "import('./lib/archive.js').then(m => { console.log(m.detectCommonPrefix(['proj/a','proj/b'])); console.log(m.detectCommonPrefix(['a','b'])); })"</automated>
